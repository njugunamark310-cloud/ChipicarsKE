# ChipicarsKE

## Project Description

ChipicarsKE is a Kenyan automotive marketplace website that allows users to browse vehicles, search and filter listings, compare vehicles, save favourites, manage a personal garage, and submit vehicles for sale. The website provides an interactive and responsive experience using HTML, CSS, and JavaScript.

## Problem Statement

Finding and comparing vehicles online can be difficult when information is spread across different platforms. ChipicarsKE aims to provide a simple and user-friendly platform where users can easily discover vehicles, compare options, save vehicles they are interested in, and explore selling opportunities.

## Features

- Responsive multi-page automotive marketplace
- Home, Cars, Compare, Garage, Sell and Contact pages
- Vehicle search and filtering
- Vehicle comparison functionality
- Favourite vehicles
- Personal vehicle garage
- Vehicle selling form
- Contact form with validation
- Data persistence using LocalStorage
- Dynamic DOM manipulation
- Interactive JavaScript features
- Modern and responsive design
